# Paper intake (copy, fill in what you can, leave the rest empty)

## Required
- **One-line claim**: We show that ... achieves ... in ..., because ...
- **Task**: Given [input], we [estimate / generate / detect / defend] [output]. Uses: [A], [B].
- **Prior approach**: Most methods [mechanism]. They assume [assumption].
- **Gap + reason**: When [condition], they [observable failure], because [technical reason].
- **Method**: [Name]: (1) [component]: [mechanism]; (2) [component]: [mechanism].
- **Evidence** (one line per result): on [benchmark/setting], [metric] [ours] vs. [baseline] = [numbers] ([table/figure]).

## Recommended (these make the paper memorable)
- **Key insight**: [property of the problem] allows [our design].
- **Closest work**: [X]: differs from us in [specific aspect]. [Y]: ...
- **Handle** (a short name for the idea, not the method): ...
- **Concrete example**: ...
- **What is surprising**: ...
- **Efficiency / integration / supported inputs**: ...
- **What it changes for the field**: ...
- **Limitations** (they scope the claims; listed in the report): fails when ...; costs ...

## Setup
- **Venue / page limit**: e.g. ACL, 8 pages (profiles: `references/venues.json`)
- **Sections to write**: title / abstract / introduction / method / evaluation / figures
- **Files**: main `.tex`, `.bib`, result files (CSV, logs, tables)
